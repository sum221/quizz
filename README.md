# 🎯 Simple Quiz App

Eine datensparsame, einfache Quiz-App für Ersteller und Spieler.

## Features

- ✅ **Ersteller**: Login mit Email, Quiz erstellen, Link generieren
- ✅ **Spieler**: Kein Login nötig, nur Link/QR-Code erforderlich
- ✅ **Datenschutz**: Keine Tracking-Pixel, minimale Datenübertragung
- ✅ **Responsive**: Funktioniert auf Desktop und Mobile

## Installation & Start

```bash
# Abhängigkeiten installieren
npm install

# Server starten
npm start
